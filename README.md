## 👨‍💻 About Me

I'm a **software engineer from India** who builds complete products, from the interface a user taps to the API, database and infrastructure behind it.

- 🌐 **Full-stack:** responsive web applications with authentication, database integration and REST APIs.
- 📱 **Mobile:** cross-platform apps built with **React Native and Expo**.
- ⚙️ **Backend & systems:** I care about how services scale. I work with API gateways, reverse proxying, load balancing, caching and rate limiting.
- 🧠 **Problem solving:** I practice data structures and algorithms on LeetCode, HackerRank, HackerEarth and GeeksforGeeks, and I apply that thinking to engineering decisions.

I'm currently open to **Software Engineer / SDE internships and entry-level roles** in full-stack, backend and mobile development.
